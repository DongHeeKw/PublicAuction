# 24. Owner actions & learning-first kick-off

## 당신의 역할: 기술 승인자가 아니라 제품 방향과 학습
| 시점 | 사용자가 하는 일 | Agent가 대신 책임지는 일 |
|---|---|---|
| 시작 | 공개 공매에 관심 있는 사용자의 가장 중요한 검색 질문 3개 적기 | 공고→물건→결과 데이터 모델 및 테스트 |
| API 접근 | 공공데이터포털 API 활용 신청 필요 시 계정 승인 | 실제 샘플 요청·응답 계약·오류/중복 테스트 |
| 첫 화면 | 인기 유형/검색/가격 필드가 이해되는지 피드백 | 집계 분모·기간·통계 정확성 |
| 첫 배포 | 공개할지·상품 유료화할지 제품 결정 | CI·비밀키·보안·장애·법률 위험 경고 |
| 학습 | tests → domain → adapter → UI 순서로 읽기 | 라인별 해설과 실제 실패·통과 로그 |

## 제품 스토리
PA-U01: 이용자로서 유형별 공고를 검색하고 원본 링크를 확인한다. 정상·종료·취소 공고를 구별한다.
PA-U02: 유형에 관한 **공식 과거 집계**를 확인한다. 공개된 집계범위가 지역/부동산 단위면 동산·차량 실입찰 수처럼 확대 해석하지 않는다.
PA-U03: 조회수 높은 콘텐츠는 공식 입찰 실적이 아닌 '사이트 내 관심'으로 별도 표시한다.
PA-U04: 이력이 있는 경우 같은 물건·회차 식별자를 검증한 뒤 비교하고, 그렇지 않으면 비교하지 않는다.
PA-U05: 회원가입 없이 검색하고, 필요하면 로컬 비교목록을 사용한다.

## 필수 Agent 학습 산출물
`PA-006` 인기 유형 기능: 주어진 원시 5건의 분모/분자를 보여주는 표, 집계순서의 순수함수, 누락시 INSUFFICIENT_DATA, RED/GREEN 출력, 화면 카드 샘플을 한 PR에 배포. 사용자에게 SQL 승인 요구 금지.

## 사업상 결정 필요
직접 입찰/낙찰대리/거래 중개는 초기 scope 제외. 상업적 광고, 유료 구독, 수수료 활동은 법적·사업자·플랫폼 약관 검토 전 플래그 OFF.

## 프로젝트 실증 전에 '미확인'
원본 API 권한, 개별 항목 가용성, 실시간 입찰자 수, 물건 이미지 저작권, 물건별 재판매가격 추정.
